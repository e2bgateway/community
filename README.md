# E2BGateway Community

Welcome! E2BGateway is excited you are interested in our community.

E2BGateway is a unified gateway that enables the official [E2B](https://e2b.dev/) client to interoperate with multiple agent runtimes including agent-sandbox and OpenSandbox, delivering standardized sandbox APIs for AI agents.

This repository contains helpful information regarding the structure and functioning of the e2bgateway community, including how to get involved.

## Communication Channels

If you're interested in participating with the e2bgateway community, come talk to us!

* Subscribe to the [e2bgateway community calendar](https://calendar.google.com/calendar/u/0/embed?src=ae6ae6d93cce74ae42d1be68bcab8154ffbc582cf1bdcef49069afcb090478ca@group.calendar.google.com&ctz=Asia/Hong_Kong)
* We are available in the [e2bgateway discord](https://discord.gg/9PnGKvwSb)
* To report security issues, please use [GitHub Security Advisories](https://github.com/e2bgateway/e2bgateway/security/advisories/new) on the main repository
* File bugs and feature requests on [GitHub Issues](https://github.com/e2bgateway/e2bgateway/issues)

## Community Meetings

To join a community meeting, add the [e2bgateway calendar](https://calendar.google.com/calendar/u/0/embed?src=ae6ae6d93cce74ae42d1be68bcab8154ffbc582cf1bdcef49069afcb090478ca@group.calendar.google.com&ctz=Asia/Hong_Kong) to your Google account. Then, you can find event details on the calendar.

Community meetings are held on [Google Meet](https://meet.google.com/ccm-ssac-ncn). Everyone is welcome!

Meeting notes and agendas are published in the [community meeting doc](https://docs.google.com/document/d/1HibRm0qScSt96UEYX4UNUWzFpHpfNon41AwwhpjIA9M/edit?usp=sharing).
